# MyFlix

Movie Hub is a web application that allows users to browse, search, and view information about movies. It features a React-based frontend and an Express.js backend.

## Features

- Search movies by title
- View details of a movie
- Responsive design for mobile and desktop
- Backend API for fetching movie data

## Technologies Used

### Frontend:
- React.js
- CSS/SCSS

### Backend:
- Express.js
- Node.js

## Setup and Installation

### Prerequisites

- Node.js installed
- Git installed

### Steps

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/movie-hub.git
   ```

2. Navigate to the project directory:
   ```bash
   cd movie-hub
   ```

3. Install dependencies for both frontend and backend:
   ```bash
   cd frontend
   npm install
   cd ../backend
   npm install
   ```

4. Start the development server:
   ```bash
   cd frontend
   npm start
   cd ../backend
   node server.js
   ```

5. Open your browser and navigate to `http://localhost:3000` for the front end.

## Usage

1. Search for movies by entering a title in the search bar.
2. Click on a movie to view detailed information.
